# AI Blend

AI Blend is a static HTML site. The home page title is "AI Blend - Cross-Platform AI Orchestration Hub", and the navigation brand is AI Blend. The pages are marketing and account screens, not a model-hosting backend.

## Overview

The repository root is HTML, CSS, and JavaScript. Pages include features, pricing, about, blog, careers, community, contact, support, documentation, demo, login, register, credentials, dashboard, and executions. `index.html` links `styles.css`. There is no `package.json` and no LICENSE file.

The repository homepage is https://1-cross-platform-ai-orchestration-h.vercel.app. The GitHub name is left unchanged.

## Features

Pages present in the repository root:

- Home, features, pricing, about, blog, careers, and community
- Contact, support, and documentation
- Demo, login, register, and credentials
- Dashboard and executions

## Tech Stack

| Technology | Where it shows up |
|---|---|
| HTML | `index.html` and the other page files |
| CSS | `styles.css`, `auth.css`, `dashboard.css`, `credentials.css` |
| JavaScript | `script.js`, `auth.js`, `dashboard.js`, `credentials.js` |

## Architecture

Static pages. No API server or model runtime is in this repository.

## Installation

```bash

cd 1.-Cross-Platform-AI-Orchestration-Hub--AI-Blend-
```

Open `index.html`.

Use the nav on the home page for features and use cases. Account pages are `login.html` and `register.html`. Dashboard markup is `dashboard.html`.
